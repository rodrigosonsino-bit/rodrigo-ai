Voz local via MLX (LLM Qwen3-4B-Instruct-2507-4bit + Whisper + TTS do macOS). Fases 1 a 4 já implementadas, testadas e aceitas com voz real.

POSIÇÃO DO AGENTE IMPLEMENTADOR (declarada, para você atacar)

Eu escrevi esse plano e defendo estas decisões:
1. BM25 léxico em TypeScript no processo Node é suficiente para um corpus de 45 seções / 27.461 caracteres — embeddings seriam over-engineering e custariam latência e memória que não sobram.
2. Recuperar dentro de sessionManager.runTurn(), de forma síncrona, é seguro e não precisa de caminho de cancelamento novo.
3. Injetar o trecho ENTRE o prompt do agente e o bloco VOICE_SAFETY_AND_OUTPUT_CONSTRAINTS preserva a propriedade de precedência de instrução que a Fase 4 estabeleceu.
4. Um teto em caracteres (MAX_CHARS 1400) é mitigação suficiente para o fato de que MAX_CONTEXT_TOKENS nunca é aplicado no código.
5. Usar só o transcript do turno corrente como query (ignorando o histórico) é a escolha certa.
6. A degradação honesta (corpus ausente => módulo indisponível, sistema funciona como na Fase 4) está corretamente desenhada.

PONTOS QUE EU SUSPEITO QUE ESTÃO FRACOS (ataque primeiro, mas não só)

a) O pseudocódigo do BM25 em 6.3: a matemática está correta? O cálculo de IDF, a normalização por comprimento, o critério de corte por MIN_SCORE 1.0 (esse valor é defensável em termos absolutos, ou é um número inventado que não significa nada numa escala BM25 que varia com o corpus?).
b) O `break` no loop de seleção quando score < MIN_SCORE combinado com o `continue` quando estoura MAX_CHARS — essa combinação produz o comportamento descrito em D4?
c) Determinismo: a ordenação por score com desempate por headingPath é realmente determinística dado que score é ponto flutuante?
d) A query usar só o transcript: qual o custo real disso em conversa por voz, onde perguntas de continuação são a norma?
e) Segurança: o corpus é material do usuário, mas o texto recuperado entra no system prompt. Existe algum caminho em que conteúdo do corpus altere o comportamento de forma indesejada (por exemplo, uma seção do corpus que contenha instruções imperativas)?
f) A medição de latência proposta (D10) é suficiente para detectar regressão, dado que bench-voice usa perguntas curtas que historicamente NÃO exercitam o caminho de Teologia/Virtologia?
